# Security Policy

## Supported Versions

Security updates and advisory feed releases apply to the latest release tag on `main`.

## Reporting a Vulnerability

If you discover a vulnerability in Wide Rules (such as catastrophic regex backtracking, supply-chain checksum bypass, or unsafe deserialization):

1. Open a private GitHub Security Advisory at https://github.com/sl4de0day/wide-rules/security/advisories/new whenever possible.
2. Provide reproduction steps, affected rule IDs or scripts, and a minimal test payload.
3. Avoid publishing exploit details until a fix and updated `dist/SHA256SUMS` bundle are released.
